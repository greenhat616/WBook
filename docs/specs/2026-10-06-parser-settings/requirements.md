# 解析与渲染设置：需求

- 日期：2026-10-06
- 状态：已实施并验证
- 设计：[design.md](design.md)；任务：[tasks.md](tasks.md)；证据：[verification.md](verification.md)

## R1：全局设置

- 独立设置页（`/settings`），由 App Bar 的设置按钮进入。
- 内容：目录解析规则（结构、章 / 卷标记、标题长度、分卷方式、每卷章数、均分段数）、广告过滤开关、渲染布局与语言、自定义样式表与可覆写的正文模板。
- 持久化在后端配置目录的 `settings.toml`；Tauri 与浏览器模式、所有窗口共享同一份。文件缺失时使用默认值；文件损坏时启动不失败，回落到默认值并在设置页提示，用户保存后覆盖。
- 保存前由后端校验（解析规则可编译、模板可编译），非法设置不落盘。

## R2：Session 设置

- 新建 Session 时复制当时的全局设置（快照）；之后全局设置的修改不影响已有 Session。
- Session 设置存在后端 workspace，修改走带 revision 的写操作；多窗口通过快照 revision 变化同步。
- 工作台“解析规则”面板读写本 Session 的解析设置，例如切换为“不分卷”后试解析。
- 渲染相关项（布局、语言、样式表、模板）放在 Session 设置页（`/sessions/$sessionId/settings`），与全局设置页共用编辑器，并提供“恢复为全局设置”。
- 试解析、预览、导出均使用 Session 当前设置，不再由前端在每次调用时拼装配置。

## R3：渲染模板

- 可覆写 `style.css`、`document.xhtml`、`section.xhtml`、`paragraph.xhtml`；未覆写的项使用内置模板。设置页能查看内置模板作为起点。
- `package.xml` 与导航条目不可覆写，保证包结构与 EPUB 校验前提不被破坏。
- 自定义模板仍启用 XML 转义；生成物照常经过导出校验，模板产生的非法 XHTML 在导出时报告。

## 范围边界

不提供多套命名预设、设置导入导出、任意正则规则编辑器或 Session 设置持久化（Session 本身尚不持久）。过滤器只在初始化时运行，初始化后修改过滤开关不回溯。

## 验收

- core：设置 toml 往返、缺失字段取默认、损坏文件回落；解析设置到 `TocParserConfig` 的映射与原前端一致；模板覆写参与渲染且非法模板被拒绝；Session 设置修改递增 revision 并作废预览。
- 前端：设置页加载 / 保存 / 校验错误；Session 解析面板与设置页读写 Session 设置；创建 Session 不再传入解析配置。
- 绑定一致性、类型检查、前后端测试与 lint 通过。
